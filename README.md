# Finanças da Casa V4.3

Pacote final dos blocos 7, 8, 9 e 10, mantendo todas as funções das versões anteriores.

## Novidades
- dashboard orientado a decisões;
- principais categorias e comparação mensal;
- projeção configurável da escola e cenário de ponte da reserva;
- relatórios por período;
- exportação de transações e orçamentos em CSV;
- backup completo em JSON;
- refinamentos de hierarquia, foco e responsividade.

## Instalação
1. Execute MIGRACAO-V4.3-COPIAR.txt no SQL Editor do Supabase.
2. Publique no GitHub todos os arquivos, exceto os dois arquivos de migração.
